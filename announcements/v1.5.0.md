## LinkedIn

```
"No quiero tests" no debería dejarte sin plan de ejecución.

Acabo de publicar sdd-creator v1.5.0.

Hasta ahora, si decías que no querías tests, la skill se declaraba no aplicable: te dejaba con el spec y el plan, pero sin tasks.md. Resultado: improvisabas la ejecución. Justo lo que SDD existe para evitar.

Lo que cambia:

→ Modo sin TDD completo. Cada criterio del spec se convierte en una tarea de construcción emparejada con una verificación manual escrita como Given / When / Then, con su línea para anotar el resultado.

→ Solo si lo pides tú. El agente nunca te propone ese modo ni lo infiere de "hazlo rápido" o "es un prototipo". La prisa recorta alcance, no verificación.

→ La matriz de cobertura sigue bloqueando el hand-off. Sin runner es la única señal de completitud que queda, así que ahí importa más, no menos.

→ Convertible. Si añades un runner más adelante, cada verificación se convierte en un test 1:1 sin reescribir el spec.

Los criterios de aceptación sobreviven. Solo cambia quién los verifica.

Spec first. Code after.

Instálalo:
📦 npx skills@latest add bezael/sdd-creator
🔗 github.com/bezael/sdd-creator
```
