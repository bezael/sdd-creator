# Marketing skills

Skills for selling digital products: offers, sales emails, landing pages, launches and customer research. They write and analyze copy **in Spanish**, so their instructions are in Spanish too.

This folder is its own Claude Code plugin, `dominicode-marketing` (`.claude-plugin/plugin.json`), listed in the repo's marketplace next to `dominicode-sdd-creator`. Install it with `/plugin install dominicode-marketing@dominicode`.

| Skill | Description |
|-------|-------------|
| [dominicode-sales-email-isra-hormozi](./dominicode-sales-email-isra-hormozi/SKILL.md) | Sales and launch emails with Isra Bravo's voice and Hormozi-style offer stacking. |
| [hormozi-offer-builder](./hormozi-offer-builder/SKILL.md) | Builds or fixes an offer with the Value Equation and its six dimensions. |
| [hormozi-landing-audit](./hormozi-landing-audit/SKILL.md) | Scores a landing or sales page and rewrites its hero and CTA. |
| [dominicode-launch-guide](./dominicode-launch-guide/SKILL.md) | Step-by-step launch guidance for courses, KDP books, SaaS, memberships and workshops. |
| [icp-community-research](./icp-community-research/SKILL.md) | Validates an ICP from community comments and drafts short, non-salesy replies. |

`icp-community-research` reads its hypothesis from `config/icp.md`. Only `config/icp.template.md` ships; your filled `icp.md` is gitignored.
